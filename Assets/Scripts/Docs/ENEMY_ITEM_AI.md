# EnemyのItem取得AI

## 判断順序

逃走・逃走解除の安全確認 → 実行中のBlock設置後ジャンプの完了 → Item取得 → Playerへの接近・攻撃。
移動アニメーション中は従来どおり新しい行動を開始しない。

## 取得目標

- 初回選択は難易度のDetectionRange内。Itemの足元にBlockがあり、落下していないものに限る。
- 爆風距離/同時設置数がItemの上限未満の場合だけ狙う。上限品を目的とした移動はしない。
- Dijkstra法で歩行・1段ジャンプ・水平移動後の降下を探索し、移動時間とAI行動間隔を含む見積時間が最も短いItemを選ぶ。
- Item取得経路ではBlockを設置しない。予測爆風セルは到着前に通れそうでも除外する保守的なルール。
- 到着時刻の照合に加え、ジャンプ上空と落下経路も確認する。将来新たに設置されるBombや、Item落下先を先読みするものではない。

## 往復抑制と再検証

- 目標と経路を保持し、新しいItemが出ても途中で乗り換えない。
- 毎思考で残り経路の障害物・足場・爆風情報を検証する。
- Item消失/落下再開/位置変更/強化上限/時間切れ/経路無効/行動失敗で計画を解除し、再探索に待ち時間を入れる。
- Item.SpawnVersionでプール再出現を識別し、同じ参照の別Itemを追跡し続けない。
- 危険時は取得を中断してEscape。既存の行き詰まり待機中も危険判定は実行する。

## 設定

EnemyAISettingsの各難易度にItem Collectionを追加。既存Assetでも既定値で有効。

- Collect Items: 取得行動の有効/無効。
- Item Search Interval: 新しい目標を探す間隔（既定0.8秒）。
- Item Retry Delay: 無効な取得計画を解除した後の再探索待ち（既定2秒）。
- Item Plan Timeout: 1目標を追う最大時間と初回経路見積の上限（既定10秒）。
- Detection Range: Player検知と同じ範囲を初回のItem検知にも使用する。

## Play Mode確認（未実施）

1. 地上に着地したItemへ向かい、CollectItemログとEnemyの能力上昇を確認。
2. 取得経路にBombを置く。計画を解除し、現在地が危険ならEscapeする。
3. 取得目標より近いItemを後から出しても、元の目標を維持する。
4. Playerが先に取得した場合や、目標がプールから別位置へ再出現した場合に追跡を解除する。
5. 段上/段下のItemへジャンプ/降下して向かう。落下中のItemは狙わない。
6. 強化上限・到達不能・爆風内のItemを狙わず、攻撃行動へ戻る。
7. Collect Itemsを無効にすると従来の接近・攻撃を行う。

C#コンパイルは確認済み。探索の安全性は現在のGridDangerMapの予測範囲に依存するため、実機テストは別途必要。
